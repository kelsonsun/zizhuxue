# 自主学

用你自己需要的、喜欢的、真实发生过的内容学英语。打开即可用，不用登录。数据只保存在你这台设备的浏览器里。

**试用地址：** https://kelsonsun.github.io/zizhuxue/

这是一个公开网页。请不要在这里上传私人资料。AI 密钥如果要配置，只存在你自己的手机或电脑上，不会进这个仓库。

## 加到手机主屏幕（打开就能用）

**iPhone / iPad（必须用 Safari，不要用 Chrome）：**
1. 用 Safari 打开上面的试用地址。
2. 点底部分享按钮（方框加向上箭头）。
3. 滑到「添加到主屏幕」，再点「添加」。

**安卓（建议用 Chrome）：**
1. 用 Chrome 打开上面的试用地址。
2. 点右上角菜单（三个点）。
3. 选择「添加到主屏幕」或「安装应用」，再确认。

加好以后，主屏幕上会有「自主学」图标，点开即可使用，不用先打开浏览器再登录。

- 第一版自带一份 5 句诊所对话示例，可随时删除。

- 云同步、手机/电脑安装包还没做，换设备请先在「我的」里导出 JSON 备份。
